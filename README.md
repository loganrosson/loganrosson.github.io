# loganrosson.github.io

My personal portfolio site. I'm an Information Systems (Honors) student at the University of Utah, graduating May 2027.

**Live site:** https://loganrosson.github.io

Plain HTML and CSS with a bit of JavaScript, no build step, hosted on GitHub Pages.

- `index.html`: projects, experience, community, education and skills
- `about.html`: more about me
- `pronto.html`, `chatbot-qa.html`, `thesis.html`: project case studies
- `404.html`: the page-not-found page
- `img/`: photos and project screenshots
- `Logan_Rosson_Resume.pdf`: the resume linked from the site

The hand-drawn SVG scenes (a city skyline, Mt. Fuji with a passing Shinkansen and a sunset over the sea) and the seasonal weather on the home page are drawn and animated right in the page.
